# Final Assignment

## Overview
This folder contains the final assignment for the IBM Data Science course. The assignment is designed to showcase the skills and knowledge acquired throughout the course by tackling a real-world problem through data analysis and visualization.

## Contents
- **notebooks/**: Jupyter notebooks containing the analysis and findings.
- **data/**: Dataset(s) used for analysis.
- **images/**: Images and plots generated during the analysis.
- **README.md**: Documentation for the final assignment.

## How to Run (Jupyter)
To run the Jupyter notebooks in this folder, follow these steps:
1. Make sure you have Python and Jupyter installed.
2. Clone the repository: `git clone https://github.com/mingshen-yen/IBM-data-science.git`
3. Navigate to the final_assignment folder: `cd IBM-data-science/final_assignment`
4. Start Jupyter Notebook: `jupyter notebook`
5. Open the desired notebook and run the cells to see the analysis.
